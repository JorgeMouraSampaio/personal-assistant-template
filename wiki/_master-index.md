# Knowledge Base

The front door to the wiki. Every topic gets its own folder under `wiki/` with an
`_index.md`; this table lists them. The wiki is **LLM-owned synthesis** built from
the immutable sources in `raw/` and the structured notes in `Resources/`. Wiki
pages carry **no tags and no frontmatter**, so they never appear in any Base or
kanban board.

Read order when answering a question: this file → the topic's `_index.md` → the
articles.
